# Формат табличного поля (FormElements27, 8.3.27)

Источник: обычные формы типовой конфигурации в EDT-проекте (`Form.oform`). Статистика собрана по
100 табличным полям и 1723 колонкам форм документов и справочников; сами формы в репозиторий не
входят. Код: `src/one_c_form_compiler/core/table_field.py`.

## Элемент

`raw[0]` = `ea83fe3a-ac3c-4cce-8045-3dddf35b28b1` (тип «ТабличноеПоле»), `raw[1]` = id.

| Путь | Что |
|---|---|
| `raw[2][1]` | `["Pattern", ["#", <typeId>]]` — тип данных (тип табличной части / реквизита формы) |
| `raw[2][2][0]` | стиль `["13", …]` |
| `raw[2][2][1]` | свойства `["17", <флаги>, …]` |
| `raw[2][2][1][23]` | колонки: `[<N>, колонка1, …, колонкаN]` |
| `raw[2][4]` | события табличного поля: `[<N>, [<id>, e1692cc2-…, ["3", "<Процедура>", …]], …]`, по возрастанию id |
| `raw[3]` | геометрия и привязки — как у остальных элементов |
| `raw[4]` | `["14", "<Имя>", …]` |

Привязка табличного поля — в источниках данных формы:

* к табличной части основного реквизита: `[id, ["2", [<id основного реквизита>], ["0", <UUID ТЧ>]]]`;
* к табличной части другого реквизита формы: `[id, ["2", [<id реквизита формы>], ["0", <UUID ТЧ>]]]`;
* к реквизиту формы целиком (таблица значений, набор записей): `[id, ["1", [<id реквизита формы>]]]`.

## Колонка

`["c2cf1953-2796-4fe2-b78c-ff84140b124e", ["1", ["8", <свойства>, <Данные>, <ДанныеФлажка>, <ДанныеКартинки>], "0", "0"]]`

Три пути к данным одного вида: `["0", <UUID реквизита ТЧ>]`; `["-2"]` — `НомерСтроки`; `["-1"]` — нет (колонка без данных
заполняется в `ПриВыводеСтроки`).

Статистика по 3695 обычным формам типовой конфигурации (4184 табличных поля, из их колонок этого вида —
11360):

| Путь | Значения |
|---|---|
| Данные | `["0", UUID]` 8414, `["-1"]` 1996, `["-2"]` 823, другие стандартные (`["-6"]`, `["-101"]` …) и `["1"…"3", UUID]` у наборов записей регистров бухгалтерии 127 |
| ДанныеФлажка | `["-1"]` 10972, `["0", UUID]` 383, стандартные 5 |
| ДанныеКартинки | `["-1"]` 11360 |

| Индекс свойств | Что |
|---|---|
| 1 | заголовок (локализованная строка) |
| 4 | ширина: число в кратчайшей записи платформы (`1e2` = 100, `1.2e2` = 120, `123`, `112.28…`) |
| 5, 6 | порядковые номера колонки в таблице (уникальны; новая колонка = максимум + 1) |
| 30 | имя колонки |
| 35 | тип значения `["Pattern", …]` |
| 38 | тип элемента ячейки: `381ed624-…` (поле ввода) |
| 39 | `[["#base64:…"], "0"]` — сериализованный элемент ячейки (в 1325 из 1723 колонок; у 398 колонок без своего элемента ячейки свойств 39) |

### Колонка-флажок табличной части

383 колонки с реквизитом в `ДанныеФлажка`: у 355 `Данные` = `["-1"]`, у 247 из них нет своего элемента
ячейки (в свойствах 39 элементов, `свойства[38]` = нулевой UUID вместо типа элемента ячейки). Так пишет
`add_column` с `"checkbox": true`: `Данные` = `["-1"]`, `ДанныеФлажка` = `["0", <UUID реквизита Булево>]`,
свойства без `[39]`, `свойства[38]` = `00000000-0000-0000-0000-000000000000`, `свойства[35]` =
`["Pattern", ["B"]]`.

### Путь через точку

Ни одной колонки табличного поля с многозвенным путём (`Реквизит.Подреквизит`) в корпусе нет: каждый путь
— один шаг. Многозвенные пути есть только у полей ввода, в источниках данных формы:
`[id, ["3", [<реквизит формы>], ["0", <UUID реквизита>], ["0", <UUID реквизита ссылочного объекта>]]]`
(391 поле). Значения вида «реквизит ссылки» в колонках типовые формы показывают в колонке без данных и
задают текст в `ПриВыводеСтроки` (`ОформлениеСтроки.Ячейки.<Колонка>.УстановитьТекст(…)`). `add_column`
с `data` через точку делает так же: колонка без данных и без своего элемента ячейки, тип — тип последнего
реквизита цепочки (проверенной по `.mdo` ссылочных объектов EDT-проекта), строка в начале обработчика
`ПриВыводеСтроки` таблицы с меткой `// one-c-form-compiler: <Таблица>.<Колонка> = <путь>`.

### Элемент ячейки (`свойства[39]`)

`base64` → 18 байт заголовка `0201534b6ff4888dc14ea0d5ebb6bda0a70d` (одинаков во всех 1145 проверенных
блоках) → raw deflate → 8 байт длины (little endian) + текст в скобочном формате с BOM.

Текст — это то же, что `raw[2]` поля ввода: `[9, ["Pattern", …], [[стиль], [свойства]], […], <события>, …]`.
События ячейки лежат в `[4]` и имеют те же id, что у поля ввода.
